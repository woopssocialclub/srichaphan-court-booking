```

┌──────────────────┐  ดูตาราง/จอง  ┌──────────────────────┐  SQL  ┌──────────────────────────────┐
│  หน้าเว็บจอง       │ ────────────▶ │ /api  (api/index.js) │ ────▶ │ ฐานข้อมูล PostgreSQL           │
│  (index.html)    │ ◀──────────── │ ตรวจสิทธิ์ทุกครั้ง       │ ◀──── │ roles · settings · users ·   │
└──────────────────┘  ส่งสลิป(รูป)  │ คิดราคา · กันจองซ้อน   │       │ bookings                     │
                                  └──────────┬───────────┘       ├──────────────────────────────┤
                                             └─────────────────▶ │ Storage: bucket "slips"      │
                                                   เก็บรูปสลิป    │ (private)                    │
                                                                 └──────────────────────────────┘
```

**ขั้นตอนการจอง 1 ครั้ง**

```
เลือกช่อง → ยืนยัน → [รอชำระเงิน] ──อัปโหลดสลิปภายใน 30 นาที──▶ [รอตรวจสลิป] ──แอดมินยืนยัน──▶ [ยืนยันแล้ว] ✅
                         │                                              │
                         └─ ไม่ส่งสลิปใน 30 นาที → [หมดเวลาชำระ]        └─ แอดมินปฏิเสธ → [สลิปไม่ผ่าน]
                            (ช่องว่าง ให้คนอื่นจองได้)                       (ช่องว่าง ให้คนอื่นจองได้)
```

- ระหว่าง **รอชำระ / รอตรวจสลิป** ช่องนั้นถูกกันไว้ คนอื่นจองซ้อนไม่ได้
- **กันจองซ้อนที่ระดับฐานข้อมูล** — ต่อให้ 10 คนกดช่องเดียวกันในเสี้ยววินาทีเดียวกัน ได้คนเดียวเสมอ (ทดสอบแล้ว)
- **กฎทุกข้อตรวจที่หลังบ้าน** (ราคา, จองล่วงหน้ากี่วัน, กี่ชั่วโมงต่อวัน ฯลฯ) — แก้หน้าเว็บในเครื่องตัวเองก็โกงไม่ได้
- **ไม่ลบข้อมูล** — ยกเลิก/หมดเวลา/ปฏิเสธ แถวยังอยู่ แค่เปลี่ยนสถานะ ย้อนดูได้เสมอ
- **สลิป** เก็บใน bucket แบบ private ดูได้เฉพาะเจ้าของการจองและแอดมิน (ลิงก์ใช้ได้ 10 นาที)
- **รหัสผ่าน** เข้ารหัสแบบ scrypt — แม้แต่คนที่เปิดฐานข้อมูลได้ก็อ่านรหัสจริงไม่ได้
- **แอดมินจองเอง** (จองให้ลูกค้าที่โทรมา / ปิดคอร์ท) = ยืนยันทันที ไม่ต้องอัปโหลดสลิป

## 2. ติดตั้งครั้งแรก (Supabase + Vercel)

**ต้องมี:** บัญชี GitHub ที่เข้า repo `srichaphan-court-booking` ได้ (สมัคร Vercel ด้วยบัญชีนี้)
และอีเมลสำหรับสมัคร Supabase (แนะนำอีเมลกลางของสนาม)

> 📝 เตรียมโน้ตไว้ 1 หน้า จะต้องจดค่า 4 อย่างระหว่างทาง: **Database password**, **Project URL**, **Secret key**, **Connection string**
> ค่าพวกนี้คือกุญแจเข้าฐานข้อมูล — **ห้ามส่งในแชทกลุ่ม ห้ามแปะในไฟล์บน GitHub**

### ขั้นที่ 1 — สร้างโปรเจกต์ Supabase

1. เปิด [supabase.com](https://supabase.com) → **Start your project** → สมัคร (ใช้ GitHub หรืออีเมลก็ได้)
2. **New project** → กรอก
   | ช่อง | ใส่ |
   |---|---|
   | Organization | ตั้งชื่อเช่น `Srichaphan` (ครั้งแรกจะให้สร้าง) |
   | Project name | `srichaphan-court-booking` |
   | Database password | กด **Generate a password** → **คัดลอกจดไว้** (ใช้ในขั้นที่ 4) |
   | Region | **Southeast Asia (Singapore)** — ใกล้ไทยที่สุด เว็บจะเร็ว |
   | Pricing plan | **Free** |
3. กด **Create new project** → รอ 1–2 นาทีจนหน้าโปรเจกต์ขึ้น

### ขั้นที่ 2 — สร้างตารางในฐานข้อมูล

1. เมนูซ้าย **SQL Editor** (ไอคอน `>_`) → **+ New query** (หรือ "New SQL snippet")
2. เปิดไฟล์ [`supabase/schema.sql`](../supabase/schema.sql) บน GitHub → กด **Copy raw file** → วางในช่อง SQL
3. กด **Run** (หรือ Ctrl+Enter) → ด้านล่างต้องขึ้น **Success. No rows returned**
   (ถ้าขึ้นหน้าต่างเตือนเรื่อง "destructive operation" ให้กด **Run this query** — ไฟล์นี้ไม่ลบข้อมูลอะไร)
4. เมนูซ้าย **Table Editor** → ต้องเห็นตาราง **bookings**, **roles**, **settings**, **users**
   - `roles` มี 3 แถว: admin (30 วัน), member (14 วัน), user (7 วัน)
   - `settings` มี 7 แถว: ราคา 250/350, บัญชีกรุงศรี ฯลฯ
5. เมนูซ้าย **Storage** → ต้องเห็น bucket **slips** (มีป้าย Private)

> 💡 `schema.sql` **รันซ้ำได้ปลอดภัย** — ไม่ลบไม่ทับข้อมูล แค่เติมสิ่งที่ยังขาด

### ขั้นที่ 3 — เก็บค่า URL และ Secret key

1. เมนูซ้ายล่าง **Project Settings** (รูปเฟือง) → **Data API** → คัดลอก **Project URL**
   (หน้าตา `https://abcdefghijklmnop.supabase.co`) → จดไว้
2. **Project Settings → API Keys**
   - ถ้ามีแท็บ **"Publishable and secret keys"** → ส่วน **Secret keys** → กดไอคอนตา/คัดลอก key ที่ขึ้นต้นด้วย `sb_secret_...`
   - ถ้าเห็นแค่ **"Legacy API keys"** → คัดลอก **service_role** (กด Reveal) ⚠️ ไม่ใช่ `anon`
   - จดไว้ — นี่คือกุญแจสิทธิ์สูงสุด ห้ามเผยแพร่

### ขั้นที่ 4 — เก็บ Connection string

1. ปุ่ม **Connect** ด้านบนของหน้าโปรเจกต์
2. แท็บ **Connection String** → Type: **URI** → เลือก **Transaction pooler** (พอร์ต **6543**)
   ⚠️ ต้องเป็น **Transaction pooler** — ไม่ใช่ Direct connection (Vercel ต่อ Direct ไม่ได้)
3. คัดลอกมา หน้าตาประมาณ
   `postgresql://postgres.abcdefghijklmnop:[YOUR-PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres`
4. **แทน `[YOUR-PASSWORD]` ด้วย Database password จากขั้นที่ 1** (ลบวงเล็บเหลี่ยมออกด้วย) → จดไว้

### ขั้นที่ 5 — สร้าง Session secret

ค่านี้ใช้เซ็นการล็อกอิน คิดเองได้เลย: **ตัวอักษร/ตัวเลขมั่ว ๆ ยาว 40 ตัวขึ้นไป** เช่นกดสุ่มจากตัวสร้างรหัสผ่านในมือถือ
→ จดไว้ (ถ้าเปลี่ยนภายหลัง ทุกคนจะถูกล็อกเอาต์ ต้องล็อกอินใหม่)

### ขั้นที่ 6 — Deploy บน Vercel

1. เปิด [vercel.com/signup](https://vercel.com/signup) → เลือก **Hobby** (ฟรี) → **Continue with GitHub** → อนุญาต
2. หน้า Dashboard → **Add New… → Project**
3. หา **srichaphan-court-booking** → **Import**
   (ถ้าไม่เห็น repo: กด **Adjust GitHub App Permissions** → เลือก repo นี้ → Save)
4. หน้า Configure Project
   - **Framework Preset:** `Other`
   - **Root Directory:** `./` (ไม่ต้องแก้)
   - Build and Output Settings: ไม่ต้องแก้
   - เปิด **Environment Variables** → เพิ่มทีละตัว (Key ซ้าย · Value ขวา → **Add**)

     | Key | Value |
     |---|---|
     | `DATABASE_URL` | Connection string จากขั้นที่ 4 (ที่ใส่รหัสผ่านแล้ว) |
     | `SUPABASE_URL` | Project URL จากขั้นที่ 3 |
     | `SUPABASE_SERVICE_ROLE_KEY` | Secret key จากขั้นที่ 3 |
     | `SESSION_SECRET` | ค่ามั่ว ๆ จากขั้นที่ 5 |

5. กด **Deploy** → รอ ~1 นาที → ขึ้น **Congratulations!**
6. กด **Continue to Dashboard** → ช่อง **Domains** คือ URL เว็บ เช่น `srichaphan-court-booking.vercel.app`

### ขั้นที่ 7 — ทดสอบว่าต่อกันครบ

1. เปิด `https://<URL เว็บ>/api` ในเบราว์เซอร์ ต้องเห็น
   ```json
   {"ok":true,"service":"Srichaphan Tennis Academy Court Booking","database":"connected"}
   ```
2. เปิด `https://<URL เว็บ>/` → เห็นตารางคอร์ทและแถบราคา ✅

| เห็นอะไร | แก้ยังไง |
|---|---|
| `Missing environment variables: ...` | ใส่ตัวแปรที่บอกไม่ครบ → Vercel → Project → **Settings → Environment Variables** → เพิ่ม → แท็บ **Deployments** → จุดสามจุดของอันล่าสุด → **Redeploy** |
| `database_unreachable` | `DATABASE_URL` ผิด: เช็คว่าเป็น Transaction pooler (6543) และแทนรหัสผ่านแล้ว · หรือโปรเจกต์ Supabase ถูกพัก (ส่วนที่ 7) |

> ⚠️ แก้ Environment Variables แล้ว **ต้อง Redeploy** ทุกครั้งถึงจะมีผล

### ขั้นที่ 8 — ปิดเว็บเก่า

ระบบเก่า (Google Sheet + Apps Script บน GitHub Pages) เลิกใช้แล้ว
- repo `srichaphan-court-booking` บน GitHub → **Settings → Pages** → Source เลือก **None** (หรือ **Unpublish site**) → Save
- Google Sheet / Apps Script เก่า: เก็บไว้ดูหรือลบทิ้งได้ ระบบใหม่ไม่ใช้แล้ว (ข้อมูลทดสอบในนั้นไม่ได้ย้ายมา)

## 3. ตั้งแอดมินและเลเวลผู้ใช้

### บัญชีแอดมินคนแรก

เปิดเว็บ → ไอคอนคนมุมขวาบน → แท็บ **สมัครสมาชิก** → กรอกเบอร์ ชื่อ รหัสผ่าน

**คนแรกที่สมัคร (ตอนที่ระบบยังไม่มีแอดมิน) จะได้เป็นแอดมินอัตโนมัติ**
⚠️ สมัครทันทีหลัง deploy **ก่อนแชร์ลิงก์ให้คนอื่น** แล้วเช็คใน Supabase → Table Editor → `users` ว่าแถวของคุณ `role` = `admin`

หลังจากนั้นทุกคนที่สมัครจะเริ่มที่ **ผู้เล่นทั่วไป** (`user`)

### เปลี่ยนเลเวลผู้ใช้ (เช่น ตั้งเป็นสมาชิก)

**ทาง A — ในหน้าเว็บ (แนะนำ):** ล็อกอินแอดมิน → แท็บ **แอดมิน** → เลื่อนลงไปส่วน **ผู้ใช้ทั้งหมด**
→ ค้นชื่อ/เบอร์ → ดรอปดาวน์ด้านขวาเลือก **สมาชิก** → ขึ้น "อัปเดตแล้ว" มีผลทันที

<img src="images/13-admin-users.jpg" width="300" alt="หน้าจัดการผู้ใช้">

**ทาง B — ใน Supabase:** Table Editor → `users` → ดับเบิลคลิกช่อง `role` → เลือก `member` / `user` / `admin` → **Save**

> เพิ่มแอดมินคนที่ 2 ไว้เสมอ (เช่น ผู้จัดการสนาม) เผื่อแอดมินหลักลืมรหัส หรือไม่ว่างตรวจสลิป

## 4. ปรับราคา บัญชีรับเงิน และสิทธิ์

Supabase → **Table Editor** → เลือกตาราง → ดับเบิลคลิกช่องที่จะแก้ → พิมพ์ → **Save**
**มีผลทันที ไม่ต้อง deploy ใหม่** (ผู้ใช้ที่เปิดหน้าเว็บค้างไว้ รีเฟรช 1 ครั้ง)

### ตาราง `settings` — ราคา / บัญชี / เวลาชำระ

| key | ค่าตอนนี้ | ความหมาย |
|---|---|---|
| `price_day` | 250 | ราคาต่อชั่วโมง ช่วงกลางวัน (บาท) |
| `price_night` | 350 | ราคาต่อชั่วโมง ช่วงเปิดไฟ (บาท) |
| `lights_from_hour` | 18 | เริ่มคิดราคาเปิดไฟตั้งแต่ช่องนี้ (18 = ช่อง 18:00–19:00 เป็นต้นไป · ถ้าอยากให้ 17:00 เป็นราคาเปิดไฟ ใส่ 17) |
| `pay_within_minutes` | 30 | ต้องอัปโหลดสลิปภายในกี่นาทีหลังกดจอง ไม่งั้นการจองหลุด |
| `bank_name` | ธนาคารกรุงศรีอยุธยา (กรุงศรี) | ชื่อธนาคารที่แสดงในหน้าชำระเงิน |
| `bank_account_no` | 1731304053 | เลขบัญชี (ตัวเลขล้วน หน้าเว็บแสดงเป็น 173-1-30405-3) |
| `bank_account_name` | ธนากร ศรีชาพันธุ์ | ชื่อบัญชี |

> แก้เฉพาะคอลัมน์ `value` · อย่าแก้ `key`
> ราคาใหม่มีผลกับการจองที่ทำหลังจากแก้ — การจองเดิมเก็บราคาตอนจองไว้แล้ว

### ตาราง `roles` — สิทธิ์แต่ละเลเวล

| คอลัมน์ | ความหมาย | admin / member / user |
|---|---|---|
| `role` | รหัสเลเวล — **ห้ามแก้ชื่อเลเวลที่มีคนใช้อยู่** | `admin` / `member` / `user` |
| `label` | ชื่อที่แสดง รูปแบบ `ไทย / English` | ผู้ดูแล / สมาชิก / ผู้ใช้ทั่วไป |
| `advance_days` | **ดูตาราง + จองล่วงหน้าได้กี่วัน** (0 = วันนี้อย่างเดียว) | 30 / **14** / **7** |
| `max_hours_per_day` | จองได้กี่ชั่วโมงต่อวัน (รวมทุกคอร์ท) · 0 = ไม่จำกัด | 0 / 2 / 1 |
| `max_active_bookings` | การจองที่ยังไม่ถึงเวลาเล่นค้างได้กี่ช่อง · 0 = ไม่จำกัด | 0 / 4 / 2 |
| `cancel_before_hours` | **ยกเลิกได้ถึงกี่ชั่วโมงก่อนเวลาเล่น** (การจองที่ชำระแล้ว) | 0 / **3** / **3** |
| `can_book_for_others` | ใส่ชื่อคนอื่นตอนจองได้ | ✓ / – / – |
| `can_block` | ปิดคอร์ทได้ + เลือกดูวันไหนก็ได้ | ✓ / – / – |
| `can_cancel_any` | ยกเลิกของทุกคน + เห็นชื่อผู้จองในตาราง | ✓ / – / – |
| `can_manage_users` | จัดการผู้ใช้ในแท็บแอดมิน | ✓ / – / – |
| `can_confirm_payments` | **ตรวจ/ยืนยันสลิป** · การจองของคนที่มีสิทธิ์นี้ยืนยันทันทีไม่ต้องจ่ายผ่านระบบ | ✓ / – / – |
| `sort` | ลำดับการแสดง | 1 / 2 / 3 |

**ตัวอย่าง: เพิ่มเลเวล "พนักงาน"** ที่ตรวจสลิปได้แต่จัดการผู้ใช้ไม่ได้
Table Editor → `roles` → **Insert → Insert row** → `role` = `staff` · `label` = `พนักงาน / Staff` · `advance_days` = 30 ·
`max_hours_per_day` = 0 · `max_active_bookings` = 0 · `cancel_before_hours` = 0 · `can_book_for_others` = true ·
`can_confirm_payments` = true · ที่เหลือ false · `sort` = 2 → **Save** → ไปตั้งผู้ใช้เป็น `staff` ในหน้าแอดมิน

⚠️ **ห้ามลบแถว `user`** — ระบบใช้กับคนที่ยังไม่ล็อกอิน และเป็นเลเวลเริ่มต้นของคนสมัครใหม่

### จองและชำระเงิน

1. เลือกวัน → แตะช่องว่างที่ต้องการ (เลือกหลายช่องได้ตามโควต้าเลเวล) — ช่องจะขึ้น ✓ พร้อมราคา
   แถบด้านล่างบอก "เลือกแล้ว N ชั่วโมง · **รวม ฿...**" → กด **จองเลย**
2. ตรวจรายการและ **ยอดรวม** → กด **ยืนยัน**
3. ขึ้นหน้า **ชำระเงิน** บอกยอดที่ต้องโอน + บัญชีกรุงศรี (กด **คัดลอก** เลขบัญชีไปวางในแอปธนาคารได้)
   และเวลาที่ต้องส่งสลิป (**ภายใน 30 นาที**)
4. โอนเงินในแอปธนาคาร → กลับมาแตะกรอบ **📎 แตะเพื่อเลือกรูปสลิป** → เลือกรูปสลิป → **ส่งสลิป**
5. สถานะเปลี่ยนเป็น **รอตรวจสลิป** → เมื่อแอดมินยืนยัน สถานะเป็น **ยืนยันแล้ว ✅** = จองสำเร็จ

💡 ยังไม่สะดวกโอนตอนนั้น กด **ชำระทีหลัง** ได้ แล้วเข้าแท็บ **การจองของฉัน** → **ชำระเงิน / ส่งสลิป** ภายใน 30 นาที

| 🔵 รอตรวจสลิป | ส่งสลิปแล้ว รอแอดมิน | **ดูสลิป** · **ส่งสลิปใหม่** (ถ้าส่งผิดรูป) |

- เหลือน้อยกว่า 3 ชั่วโมงก่อนเล่น → ยกเลิกเองไม่ได้ ติดต่อแอดมิน

## 6. คู่มือแอดมิน

แอดมินเห็นทุกอย่างเหมือนผู้เล่น บวกกับ
- แถบวัน **30 วัน** + ช่อง **วันอื่น** เลือกวันไหนก็ได้ (ล่วงหน้าถึง 1 ปี)
- ตารางแสดง **ชื่อผู้จองทุกช่อง** (ช่องเส้นประ = ยังไม่ได้ยืนยัน)
- แท็บ **แอดมิน** ที่แถบล่าง — **เลขสีแดงบนไอคอน = จำนวนสลิปที่รอตรวจ**

### ✅ ตรวจสลิป (งานหลักทุกวัน)

แท็บ **แอดมิน** → ส่วน **รอตรวจสลิป** — แต่ละรายการบอก ชื่อ · เบอร์ (กดโทรได้) · คอร์ท/วัน/เวลา · **ยอดที่ต้องได้รับ**

1. กด **ดูสลิป** → ตรวจในแอปธนาคารของบัญชีกรุงศรีว่าเงินเข้าจริง:
   **ยอดตรง** · **ชื่อผู้รับ ธนากร ศรีชาพันธุ์** · **วันเวลาโอนหลังเวลาจอง** · ไม่ใช่สลิปเก่าที่เคยใช้
2. ถูกต้อง → **ยืนยันสลิป** → ผู้เล่นเห็นสถานะ **ยืนยันแล้ว** ทันที
3. ไม่ถูกต้อง → **ปฏิเสธ** → พิมพ์เหตุผล (เช่น "ยอดไม่ตรง" / "ไม่พบยอดเงินเข้า")
   → ผู้เล่นเห็นเหตุผล และ **ช่องว่างให้คนอื่นจองทันที**

<img src="images/14-admin-review.jpg" width="260" alt="รายการรอตรวจสลิป"> <img src="images/15-admin-slip.jpg" width="260" alt="ดูสลิปและยืนยัน">

> ⚠️ **อย่ายืนยันจากรูปสลิปอย่างเดียว** — สลิปปลอมทำได้ง่าย ให้เช็คยอดเงินเข้าในแอปธนาคารทุกครั้ง

### รอชำระ (ยังไม่ส่งสลิป)

ส่วน **รอชำระ** แสดงการจองที่ยังไม่ส่งสลิป และเวลาที่จะหมดอายุ
- ปล่อยไว้ได้ — ไม่ส่งสลิปในเวลา ระบบปล่อยช่องเอง
- ลูกค้าจ่ายเงินสด / ส่งสลิปทาง LINE แทน → กด **ยืนยัน (รับเงินแล้ว)**
- อยากปล่อยช่องเลย → **ยกเลิกการจอง**

### จองให้ผู้เล่น (ลูกค้าโทรมา / จองให้โค้ช)

เลือกช่อง → **จองเลย** → ใส่ **จองให้ (ชื่อผู้เล่น)** เช่น `คุณสมชาย (โทรจอง)` → **หมายเหตุ** (ไม่บังคับ) → **ยืนยัน**
การจองของแอดมิน **ยืนยันทันที** ไม่ต้องส่งสลิป — เก็บเงินหน้าเคาน์เตอร์ (ราคาถูกบันทึกตามช่วงเวลา)

<img src="images/11-admin-book-for.jpg" width="260" alt="จองให้ผู้เล่น">

### ปิดคอร์ท (ซ่อม / คลาสเรียน / จัดแข่ง)

เลือกช่อง (ครั้งละไม่เกิน 20 ช่อง) → **จองเลย** → เลือก **ปิดคอร์ท** → ใส่ **เหตุผลที่ปิด** (ผู้เล่นเห็นในช่องสีเหลือง) → **ยืนยัน**
ปิดวันไกล ๆ (เช่น วันแข่งเดือนหน้า) ใช้ช่อง **วันอื่น**

<img src="images/09-admin-schedule.jpg" width="260" alt="ตารางของแอดมิน"> <img src="images/10-admin-block.jpg" width="260" alt="ปิดคอร์ท">

### ยกเลิกการจองของผู้เล่น / เปิดคอร์ทคืน

แตะช่องที่มีชื่อ (หรือช่องเหลือง) → ดูรายละเอียด → **ยกเลิกการจองนี้** / **เปิดคอร์ท**
แอดมินยกเลิกได้ตลอด — ถ้าผู้เล่นจ่ายแล้ว **คืนเงินเองนอกระบบ**

<img src="images/12-admin-detail.jpg" width="260" alt="รายละเอียดการจอง">

### จัดการผู้ใช้

| ทำอะไร | วิธี |
|---|---|
| เปลี่ยนเลเวล | แท็บแอดมิน → ดรอปดาวน์ด้านขวาของชื่อ |
| ผู้ใช้ลืมรหัส | **ตั้งรหัสใหม่** → พิมพ์รหัสใหม่ (≥ 6 ตัว) → แจ้งผู้ใช้ |
| ระงับบัญชี (เช่น ส่งสลิปปลอม) | **ระงับ** → ล็อกอินไม่ได้ทันที |
| เปิดบัญชีคืน | **เปิดใช้** |

### ดูข้อมูล / สรุปรายได้ใน Supabase

- **Table Editor → bookings** — ทุกช่องที่จอง พร้อม `price` และ `status` · กด **Filter** กรองตาม `date` / `status` ได้
- อยากยกเลิกจากฐานข้อมูล → แก้ `status` เป็น `cancelled` (**อย่าลบแถว**)
- **สรุปรายได้รายเดือน**: SQL Editor → New query → วาง → Run
  ```sql
  select to_char(date, 'YYYY-MM') as month,
         count(*)        as hours_booked,
         sum(price)      as revenue_thb
  from bookings
  where status = 'confirmed' and type = 'booking'
  group by 1 order by 1 desc;
  ```
- **Storage → slips** — รูปสลิปทั้งหมด แยกโฟลเดอร์ตามรหัสการจอง (`order_id`)

- **ทดสอบก่อนขึ้นจริง**: push ขึ้น branch อื่น → Vercel สร้าง **Preview URL** แยกให้ลองก่อน (ใช้ฐานข้อมูลเดียวกัน — ระวังข้อมูลทดสอบปนข้อมูลจริง)
- **เปลี่ยนโครงสร้างฐานข้อมูล**: ถ้าอัปเดตไหนแก้ `supabase/schema.sql` ให้รันไฟล์ใหม่ใน SQL Editor อีกครั้ง (รันซ้ำได้ปลอดภัย)
- **ย้อนกลับเวอร์ชัน**: Vercel → Deployments → อันที่ใช้ได้ล่าสุด → จุดสามจุด → **Promote to Production**

ค่าที่แก้ในโค้ด (`lib/app.js` บล็อก `CONFIG`): ชื่อ/จำนวนคอร์ท, เวลาเปิด–ปิด, ล็อกอินค้างได้กี่วัน
— ราคา บัญชี และสิทธิ์ **ไม่ต้องแก้โค้ด** (ส่วนที่ 4)

## ข้อจำกัดที่ควรรู้

- **ระบบไม่ได้ตรวจสลิปอัตโนมัติ** — แอดมินต้องเช็คเงินเข้าในแอปธนาคารเองก่อนกดยืนยัน
- **ไม่มีการคืนเงินอัตโนมัติ** — ยกเลิกหลังชำระแล้ว แอดมินโอนคืนเองนอกระบบ
- ไม่มี OTP / อีเมลยืนยัน — ล็อกอินด้วยเบอร์โทร + รหัสผ่าน (ไม่ได้ยืนยันว่าเป็นเบอร์จริงของคนนั้น)
- ตารางรีเฟรชเองทุก 60 วินาที — อยากเห็นล่าสุดทันที กดเลือกวันใหม่หรือรีเฟรชหน้า

```bash
npm install

npm run dev -- --reset           # รันเว็บ + หลังบ้านในเครื่องที่ http://localhost:3000 พร้อมข้อมูลตัวอย่าง
                                 # (ใช้ DATABASE_URL ของฐานทดสอบ · ห้ามชี้ไปฐานข้อมูลจริงตอนใช้ --reset)
```
