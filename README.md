# Srichaphan Tennis Academy — ระบบจองคอร์ท

ระบบจองคอร์ทเทนนิสออนไลน์ 5 คอร์ท (C1–C5) เปิด 06:00–23:00 ทุกวัน จองรายชั่วโมง
ดูตารางและจองล่วงหน้าได้ตามเลเวล: แอดมิน 30 วัน · สมาชิก 14 วัน · ผู้เล่นทั่วไป 7 วัน

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บจองคอร์ท (เปิดผ่าน GitHub Pages) |
| `apps-script/Srichaphan_Court_Booking.gs` | ระบบหลังบ้าน — วางใน Apps Script ของ Google Sheet |
| `docs/setup-guide.md` | **คู่มือฉบับเต็ม**: ติดตั้ง · ตั้งสิทธิ์ · คู่มือผู้เล่น · คู่มือแอดมิน · แก้ปัญหา |

👉 เริ่มที่ [docs/setup-guide.md](docs/setup-guide.md)
